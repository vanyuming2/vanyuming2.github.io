# 项目路线图

## 已完成的稳定基线

- 暖色星空纪念主页、相伴计时、三封信。
- 五个边缘记忆图标、烟花提示和贪吃蛇。
- 第一块基础 Three.js 小花园。
- Life Restart 原版中文完整核心流程与本地存档。
- 30张天赋池、3次刷新、提高稀有概率、红色天赋权重。
- 开发调试入口与从0岁开始的事件预约。
- 两条文字异闻线。
- 10组特殊事件主体与蓬莱反向章节。
- 亲历铺垫、普通人生旁观传闻和收录图鉴。
- 神秘的小盒子—仙脉图录—14章修仙线—完美结局。
- 红色药丸—未加载的世界—真结局。
- 特殊事件、异闻、引擎、数据和静态构建测试。

## 近期优先级

### 1. 继续扩充特殊事件

- 宏大怪谈目标约 20 条；当前已形成香巴拉、共工、蓬莱、罗布泊、深海鲸骨、昆仑、沙海等基线。
- 恐怖怪谈目标约 20 条；当前“屋里七天”和“八尺之外”只是起点。
- 每条都要完成天赋或自然入口、铺垫、传闻、触发、阅读、收录、人生后果和测试。

### 2. 统一特殊事件阅读氛围

- 等内容规模更稳定后统一处理，不在每加一条故事时反复重做。
- 方向是“翻开一页不该存在的书”：克制的纸张、页码、细微翻页声或呼吸感、已收录印记。
- 不使用金边、巨大弹窗、促销广告式按钮和持续恐怖闪烁。

### 3. 扩充普通人生的暗示

- 添加更多不强制入线的旁观消息，让没有特殊天赋的人生也偶尔感到世界边缘有异常。
- 传闻必须稀疏，不能每几年出现一次，也不能泄露特殊事件的完整谜底。

### 4. 加固回归规则

- 为每个男性限定结局增加统一参数化测试。
- 增加开发/生产环境调试按钮可见性测试。
- 增加从天赋选择、0岁出生、触发故事、读完、继续或结束人生的浏览器级完整流程测试。
- 检查长图文在手机端的加载、内存和返回操作。

## 上线前必须完成

1. 完整执行测试与 lint。
2. 生产静态构建中确认调试入口和预览捷径不可见。
3. 手机与电脑各完整走一局普通人生、一局 resume 特殊事件和一局真结局。
4. 核对 367 张及后续新增图片在 GitHub Pages 路径下全部可访问。
5. 审查仓库大小，决定原始 `素材库/` 是否进入公开远端。
6. 核对第三方许可文件确实存在于 `dist/client`。
7. 检查本地与远端 Git 历史及 Pages 工作流，禁止 force push。
8. 获得用户当次明确发布授权后再 push/部署。

## 中长期花园

- 从观赏场景扩展为固定斜俯视的记忆摆放模式。
- 支持选物件、点格子、旋转、移动、收回、撤销。
- 纪念物数据化，并能打开已有信件、小游戏和事件图鉴。
- 先做本机 localStorage 和导出/导入，再考虑两人共享云存档。
- 不做可操控小人、车辆、复杂物理、金币、抽卡和每日任务。

## 内容终点与留白

- 20+20 是内容规模目标，不是必须填满的 KPI；宁可减少，也不要加入没有铺垫和余味的故事。
- 修仙线与真结局已经提供结构终点，后续怪谈只需暗暗契合，不需要逐条解释。
- 真结局之后保留普通纪念主页和花园，让整个项目最终仍回到两个人日常会打开的地方。
