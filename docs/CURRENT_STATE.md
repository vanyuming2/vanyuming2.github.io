## 一句话状态

项目已经形成三个相互独立但视觉相连的入口：暖星纪念主页、第一块 3D 星空花园、带完整原版数据与原创怪谈层的人生重开游戏。当前成果主要在本地，本地检查点不等于已发布到 GitHub Pages。

## 路由与完成度

### `/` 纪念主页

- 深灰黑夜空与暖黄色小星星是已确认的正式视觉基准。
- 显示万雨铭、张锦和从 `2026-04-29T00:17:00+08:00` 起经过的时间。
- 三封信记录 2007 年相识、2025 年重新聊天和 2026 年告白。
- 五个数据驱动的边缘记忆图标：大白鹅、海星、课本、聊天气泡、月夜。
- 点击图标会出现烟花和短句；收集完成后进入贪吃蛇。
- 贪吃蛇目标复用五个图标，身体平滑、尾部渐细、速度较慢，支持键盘与手机方向键。

### `/garden/` 第一块小花园

- 已接入 Three.js，固定斜俯视微缩花园，不控制人物。
- 当前是 8×8 数据地图，包含池塘、沙地、课桌、星灯、白鹅、海星、邮箱、树木、长椅等 17 个物件。
- 当前只用于观赏与验证风格；尚无摆放编辑、收藏、撤销或存档。
- 长期目标仍是 Garden Galaxy 式的记忆收藏与摆放，但必须保持现有星空网站的克制气质。

### `/remake/` 另一种人生

- 使用 Life Restart 简体中文数据和独立 TypeScript 引擎。
- 静态载入 501 个年龄档、1719 个发布事件、184 个原版天赋、165 个成就和 100 个角色；本站加载后再注入自定义天赋、事件、成就和修仙章节。
- 经典流程包括：模式选择、30 抽 3 天赋、额外刷新 3 次、属性分配、逐年推进、自动播放、总结、继承天赋、角色模式、图鉴、成就、导入导出存档。
- 本站抽卡概率提高为普通 45%、蓝色 30%、紫色 18%、橙色 7%；红色指定天赋另有单卡权重提升。
- 存档键为 `wm-zj-life-remake:v2`，仅保存到当前浏览器。
- 开发环境和本机地址显示调试工具，可选择天赋和特殊事件，并从 0 岁以玩家视角开始。生产构建隐藏调试入口。
