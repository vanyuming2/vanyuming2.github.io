# 重要决定记录

本文件只记录会影响后续开发方向的决定。新决定追加在顶部或对应主题下，不删除旧理由；若用户改变决定，注明“取代”关系。

## 2026-08-22：手账插入全部图片的网页衍生版

- 用户确认将两个本地文件夹中的全部图片插入手账，并继续此前的线上更新。
- 不直接发布约 600 MB 的本地原图；统一生成最大边 1080px 的桌面 WebP 和最大边 640px 的手机 WebP，原始文件夹继续由 Git 忽略。
- 闭合相册封面仍使用不可辨认的 18px 马赛克，只有翻开手账才显示清晰图片；一次加载当前页，并按视口预取后两页。
- 三张实际为 HEIF 数据的 `.png` 文件必须真实解码，不再用哈希色块代替。
- 图片在手账内完整显示，不裁掉主体；阅读器根据实际横竖方向缩放相框，避免大量竖图被塞进横向黑框。

## 2026-08-21：图片栏目改为含蓄的手账式单页阅览

- 取代同日“默认各展示前 8 张”的卡片墙方案：主页默认只显示两本闭合相册，不直接铺开缩略图。
- 翻开后仍在页面内阅览，不使用全屏大图；一页只显示一张，照片约占上方三分之一，其余空间留给台词与涂鸦。
- 涂鸦使用代码内独立 SVG，而不是烧进图片；每页保存类型、坐标、旋转、比例和色调，便于以后逐张替换。
- 默认每页只放 1—2 个低饱和涂鸦，避免把页面做成贴纸墙。与脸部相关的猫耳、皇冠、胡子只作为可选素材，不自动随机贴脸。
- 手账翻开期间暂时隐藏边缘记忆图标，合上后恢复；相册交互同时支持按钮、方向键和手机左右滑动。
- 清晰原图的隐私规则不变；该阶段最初仅本地展示，后续已由上方 2026-08-22 决定授权发布网页衍生版。

## 2026-08-21：私人图片先用不可辨认的马赛克占位

- 主页底部增加“生活中的图片”和“风格化图片”两个栏目，每张图片都有稳定编号和独立台词槽位。
- 清晰原图继续只留在本地并由 Git 忽略；当前公开目录只允许最大边 18px 的低分辨率马赛克占位，避免误把私人照片推送到公开 GitHub 仓库。
- 最初采用两组各展示前 8 张的卡片墙；该表现已被上方“手账式单页阅览”决定取代。
- 本阶段只做本地展示，不构成发布授权；清晰图片和正式台词留待用户逐项确认。

## 2026-08-15：每段人生只展示一种红色天赋

- 普通开局在没有红卡继承时，以 75% 概率确定本世唯一一张红色天赋；25% 的人生不出现红卡。
- 初始卡池和三次刷新共享同一个结果：若本世有红卡，刷新后仍是同一种；若本世无红卡，刷新不会反复重抽概率。
- 继承红色天赋时，它直接占用本世唯一红卡名额，不再抽取第二张。
- 所有现有特殊事件、修仙线和克苏鲁异闻都只需要一张对应红卡；真结局药丸是完美结局后的独立选择，因此不会被普通卡池限制封死，并会独占真结局人生的红卡名额。
- 原版福袋、轮盘赌和叠加态可能替换出 1048、1065、1128 等红卡；引擎必须把全部红卡视为同一互斥组，避免替换后形成第二张红卡。

## 2026-08-14：首页称呼进一步私人化

- 首页顶端不再显示“万雨铭 和 张锦”，只保留当天日期。
- 星星下方不再使用面向特定对象的称呼，改为“偶尔更新”。
- 主标题由面向特定对象的“今晚也想和你说说话”缩短为“随便看看”，让其他访客看到时更自然。
- 倒计时下方不再直白写“离见面，又近了一天”，改为更日常的“见面再说。”。
- 八月记录、当晚留言和三封信不删除，统一放进默认闭合的“私人记录”档案；封面以克制的黑色遮盖线提示内部有内容，点击后不展示原文，只显示“这部分显示有点问题，暂时隐藏内容。”。
- 删除页面最下方“这里只记我们想记的”和“万雨铭 & 张锦”的公开署名。
- 页面其他回忆和元信息本轮不作扩大删除。

## 2026-08-14：真结局不再复用原版看脸分支

- 原版事件21305—21308恢复原始数据、条件和年龄池关系，继续作为独立的虚拟世界支线。
- 红色药丸改用本站事件 `site-unloaded-hometown-entry`，在20—32岁预约触发“未加载的世界”。
- 真结局不再检查智力或相貌，也不会出现“相貌还可以，世界决定抹去记忆”等原版文案。

## 2026-08-14：调试人生允许只测试天赋

- 调试台默认不选择任何强制事件，清空存档或重新进入调试台也不会偷偷选中“未加载的世界”。
- 只选择“神秘的小盒子”等天赋时，调试人生只装载所选天赋；只有主动选中事件才会强制预约。

## 2026-08-14：建立仓库内长期记忆

- 决定：使用 `AGENTS.md`、当前状态、内容手册、技术地图、决策记录、素材清单和路线图维护长期上下文。
- 原因：项目已经跨越大量对话和多个模型，旧 `HANDOFF.md` 远远落后于实际代码。
- 执行：每个被确认的阶段结束时同步文档，关键规则同时写成测试并创建本地检查点。

## 2026-08：结局层级固定

- 完整读完任意特殊事件：成就“初识冰山一角”。
- 神秘的小盒子—《仙脉图录》—连续修仙线：完美结局。
- 完美结局后的下一次选择红色药丸，再走完未加载的世界：真结局。
- 真结局不使用金边、促销广告式视觉，必须明确显示“达成真结局”。
- 黑塞引文固定为：“我再一次站在阳光下，就像我儿时那样，我一无所有，一无所学，一无所知。”

## 2026-08：怪谈叙事保持克制

- 决定：不把谜底全部说破，不用旁白替玩家总结世界观。
- 原因：用户认为克制能最大程度制造浮想联翩。
- 标准句式参考：“你伸手掀开帷幕的一角。下一秒，周围的一切开始无声褪去。”
- 特殊事件要先在逐年记录中被遇见，再出现进入提示，不能直接跳进阅读器。

## 2026-08：强制与可选事件分开

- 强制事件：只有进入按钮，按钮与引导文字可以神秘但不夸张。
- 可选事件：提供观赏和跳过，并显示是否已经收录。
- `resume` 故事读完继续本局人生；`end-life` 才结束人生。
- 共工穿越明确是一场梦，读完后继续人生。

## 2026-08：性别由规则控制，不写进天赋宣传

- 图片与剧情需要男性时，运行时强制男性出生并过滤女性限定天赋。
- 删除特殊天赋说明里的“你生为男性”。
- 调试模式和正常人生遵守同一约束。
- 未加载的世界真结局属于红色药丸男性人生，不应在女性人生触发。

## 2026-08：普通人生保留原版内容

- 决定：普通文案和事件库继续使用 Life Restart 原版简体中文数据，不改成万雨铭与张锦的私人经历。
- 本站内容通过覆盖层添加，避免破坏上游数据关系。
- 主页中不显示显眼的许可和规则说明，但完整 MIT 许可必须继续随发布产物分发。

## 2026-08：抽卡更适合探索怪谈

- 每批天赋从 10 张扩为 30 张，选 3 张。
- 允许额外刷新 3 次。
- 稀有等级实际概率提高为 45/30/18/7。
- 神秘的小盒子、祖传药丸、克苏鲁和本站宏大怪谈天赋使用红色外观与额外权重。
- 小盒子第一次只开启“自创练气”，并用已见事件记录这次尝试；下一次再次持有小盒子时，才极大概率购买《仙脉图录》。普通人生次数不能替代这次修仙经验。
- 月白仙章之间允许出现低权重、一次性的行善小事，只改变少量属性，不能分支、不能结束人生、不能抢走主章节。
- 完美结局祝贺画面显示真实的已完成轮回数与累计年数；旧存档没有累计年数字段时从 0 安全补齐。

## 2026-08：特殊天赋优先使用具体物件

- 决定：天赋名称优先是手稿、航片、母带、磁带、石印、药丸、血脉或体质。
- 原因：抽象称号难以让玩家自然接受，也不利于在普通人生中形成可信铺垫。

## 2026-08：图文素材按原图沉浸式呈现

- 用户已说明已向作者取得同意，项目非商业、私人使用。
- 发布故事可直接使用图片；平台底部水印或界面按用户和作者意见裁掉，优先裁切而非生成式重绘。
- 原始素材与发布素材分开保存，页数和删减必须写入素材清单。

## 2026-08：长期怪谈规模

- 目标约 20 条宏大怪谈与 20 条恐怖怪谈。
- 普通人生中加入克制的旁观传闻，特殊天赋人生加入亲历铺垫。
- 所有线路最终可以在修仙线中暗暗契合，但不能把每条怪谈解释成同一个简单答案。

## 2026-08：开发调试工具

- 调试人员可以选择全天赋和特殊事件，但必须从 0 岁开始，让触发过程保持玩家视角。
- 调试入口只在开发环境或本机显示，完成上线时生产构建自动隐藏。

## 2026-08：手机端图片策略

- 主页五个记忆图标在手机端继续散落于浏览器四边，不收拢为底部工具栏。
- 原始故事图片和图标不删除；发布时另带轻量 WebP，由 `<picture>` 按手机视口选择。
- 特殊事件阅读器提前加载后两页。切页时先切换页码与加载状态，不能让上一张图继续停留并造成“按钮无效”的错觉。

## 2026-08：花园方向

- 不做可操控小人、车辆驾驶或自由漫游。
- 长期做俯视/斜俯视的漂浮星空小花园，用于记忆收藏、摆放和存档。
- 先做基础观赏花园，再验证摆放手感和手机性能。

## 2026-08-03：主页视觉基准

- 当前正式主线是深色夜空中一颗暖黄色小星星轻轻闪烁。
- 页面属于两个人的私人恋爱笔记，不是婚宴海报、简历或公开人物介绍。
- 不再使用巨型姓名、巨型标题、学历工作介绍、灰暗写实信封和持续炫技动画。
- 所有功能先在本地确认，用户明确满意后才允许上传。
