# 万雨铭 & 张锦｜我们的纪念日

一个安静、克制的单页纪念网站，记录从 2026 年 4 月 29 日 00:17（上海时间）开始一起走过的时间。

## 网站内容

- 精确显示已经走过的天、小时、分钟和秒
- 使用带时区的起点 `2026-04-29T00:17:00+08:00`
- 同时适配手机和电脑
- 支持“减少动态效果”系统设置
- 通过 GitHub Actions 自动发布到 GitHub Pages

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm ci
npm run dev
```

生成可发布的静态网站：

```bash
npm run build
```

静态文件位于 `dist/client`。推送到 `main` 分支后，GitHub Actions 会自动部署。

## 修改内容

主要页面在 `app/page.tsx`，视觉样式在 `app/globals.css`。如果以后需要调整名字、文案或起始时间，可直接修改这两个文件。
