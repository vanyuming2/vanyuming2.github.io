# 当前项目状态

> 基准日期：2026-08-21（Asia/Shanghai）
> 当前分支：`main`

## 一句话状态

项目已经形成三个相互独立但视觉相连的入口：暖星纪念主页、第一块 3D 星空花园、带完整原版数据与原创怪谈层的人生重开游戏。2026-08-21 的手机端布局与图片性能优化已进入本次 GitHub Pages 发布范围。

## 路由与完成度

### `/` 纪念主页

- 深灰黑夜空与暖黄色小星星是已确认的正式视觉基准。
- 顶端只保留当天日期，不显示两个人的名字；星星下方写“偶尔更新”，主标题为“随便看看”。
- 显示从 `2026-04-29T00:17:00+08:00` 起经过的时间。
- 八月记录、当晚留言和三封信默认收在“私人记录”涂黑档案中；访客点击后只看到“这部分显示有点问题，暂时隐藏内容。”，原内容仍保留但不在页面中显示。
- 页面底部不再显示“这里只记我们想记的”或两个人的姓名署名。
- 三封信记录 2007 年相识、2025 年重新聊天和 2026 年告白。
- 五个数据驱动的边缘记忆图标：大白鹅、海星、课本、聊天气泡、月夜。
- 手机端仍保持图标散落在浏览器四边的表现，不使用底部横排工具栏；页面实际加载 5 张 128px 轻量 WebP，原始 PNG 保留在素材目录。
- 点击图标会出现烟花和短句；收集完成后进入贪吃蛇。
- 贪吃蛇目标复用五个图标，身体平滑、尾部渐细、速度较慢，支持键盘与手机方向键。

### `/garden/` 第一块小花园

- 已接入 Three.js，固定斜俯视微缩花园，不控制人物。
- 当前是 8×8 数据地图，包含池塘、沙地、课桌、星灯、白鹅、海星、邮箱、树木、长椅等 17 个物件。
- 当前只用于观赏与验证风格；尚无摆放编辑、收藏、撤销或存档。
- 长期目标仍是 Garden Galaxy 式的记忆收藏与摆放，但必须保持现有星空网站的克制气质。

### `/remake/` 另一种人生

- 使用 Life Restart 简体中文数据和独立 TypeScript 引擎。
- 静态载入 501 个年龄档、1719 个发布事件、184 个原版天赋、165 个成就和 100 个角色；本站加载后再注入自定义天赋、事件、成就和修仙章节。
- 经典流程包括：模式选择、30 抽 3 天赋、额外刷新 3 次、属性分配、逐年推进、自动播放、总结、继承天赋、角色模式、图鉴、成就、导入导出存档。
- 本站抽卡概率提高为普通 45%、蓝色 30%、紫色 18%、橙色 7%。每段人生的四批卡池合计最多出现一种红色天赋；没有红色继承时，该人生有 75% 概率出现红卡，刷新只会保留同一种，不会暴露新的红卡。
- 存档键为 `wm-zj-life-remake:v2`，仅保存到当前浏览器。
- 开发环境和本机地址显示调试工具，可只选择天赋，或额外指定一个强制事件，并从 0 岁以玩家视角开始；默认不选择事件。生产构建隐藏调试入口。

## 当前原创内容

- 10 个特殊事件主体：未加载的世界、香巴拉世界、屋里七天、共工与祝融、蓬莱航线、罗布泊的第二次日落、七千米深处的鲸骨走廊、昆仑骸骨、沙海之下、八尺之外。
- 蓬莱航线另有“海雾另一侧”石生视角章节。
- 367 张桌面原图总计约 45.91 MB，并为每页提供 720px 手机版，共约 17.33 MB；浏览器按视口选择，不会同时下载两套。
- 特殊事件封面与阅读器在手机端使用轻量图；阅读器提前加载后两页，并在新页尚未完成时显示明确的翻页状态。
- 两条文字异闻线：白石坳借年簿、第七码头来电；每条 10 个线索。
- 16 条亲历铺垫、10 条旁观传闻，均为不进入普通随机池的预约事件。
- 首次持有小盒子只会走自创练气阶段；下一次再次持有小盒子，才会开启月白仙章。
- 14 章修仙叙事覆盖 101—499 岁，另有 7 条不影响主线的行善小事，最终接回原版事件 40050。
- 三个本站成就：初识冰山一角、完美结局、真结局。

## 结局链现状

1. 完整读完任意特殊事件，获得“初识冰山一角”。
2. 第一次携带“神秘的小盒子”时，26—59 岁只能按自己摸索的功法练气，并留下跨世记录；若活到 99 岁，会以“这一世止于练气”正常收束，不进入五百岁修仙线。
3. 下一世再次携带小盒子，才会在 26—59 岁得到《仙脉图录》，进入原版修仙机制和本站 14 章连续叙事。
4. 走到事件 40050，显示累计轮回次数和累计年数的月白祝贺画面，并获得“完美结局”。
5. 后续人生出现红色药丸选择。
6. 选择红色药丸后开始男性人生，并在 20—32 岁通过本站专属事件触发“未加载的世界”；不再复用原版21305—21308的智力和相貌审判。
7. 完整结束该故事后显示专属真结局页面和“达成真结局”。
